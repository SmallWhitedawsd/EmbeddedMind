# Troubleshooting 决策树

## 启动问题

```
上电无反应?
├── 测量VDD有无3.3V
│   ├── 无 → 检查电源电路
│   └── 有 ↓
├── 按复位键
│   ├── 有反应 → 上电复位电路问题, 加复位电容
│   └── 无反应 ↓
├── 读RCC_CSR (0x40023874)
│   ├── bit29=1 (IWDG复位) → 代码死等, 加超时+喂狗
│   ├── bit27=1 (POR) → 正常上电, 检查代码
│   └── bit25=1 (BOR) → 欠压, 检查供电
└── 示波器看晶振
    ├── 无波形 → 晶振电路问题
    └── 有波形 → 检查BOOT引脚
```

## 屏幕问题

```
屏幕不亮?
├── 背光有无
│   ├── 无 → 检查背光电路/EN引脚
│   └── 有 ↓
├── 检查SPI通信
│   ├── 无SCK → SPI配置/引脚问题
│   ├── 有SCK无响应 ↓
│   │   ├── 检查CS片选
│   │   ├── 检查波特率 (/32 vs /16)
│   │   │   └── /16黑屏 → 信号完整性, 回退/32
│   │   └── 检查初始化时序
│   │       ├── 上电沉降不足 → 加1.5s延时
│   │       └── SDRAM不ready → 加放电电阻
│   └── 有响应 ↓
│       ├── 花屏 → 检查FPC排线/降低波特率
│       └── 白屏 → 检查LT7580初始化/PLL锁定
└── 检查IWDG
    └── 30s复位 → 初始化死等, 加超时
```

## 通信问题

```
Modbus无应答?
├── 检查串口参数
│   ├── 波特率9600 8N1?
│   │   └── 不匹配 → 修正
│   └── 匹配 ↓
├── 检查485硬件
│   ├── A/B线接反? → 交换
│   ├── 供电正常? → 检查12V/24V
│   └── 匹配 ↓
├── 检查RS485收发切换
│   ├── RTS控制时序?
│   │   └── 发后RTS拉低, 等500ms
│   └── 匹配 ↓
├── 检查COM端口
│   ├── 设备管理器确认实际COM号
│   └── 端口未被占用?
└── 用串口助手排除硬件

SPI通信失败?
├── 示波器看SCK/MOSI
│   ├── 无信号 → SPI配置/引脚
│   ├── 有信号但波形差 → 降低GPIO速度
│   └── 信号正常 ↓
├── 检查CPOL/CPHA
│   └── Mode 3: CPOL=High, CPHA=2Edge
└── 检查NSS片选
```

## 触屏问题

```
触屏卡顿/无响应?
├── 首次上电卡顿?
│   ├── 是 → 检查总线竞争
│   │   ├── 移除taskENTER_CRITICAL
│   │   ├── 降低DAQ频率 (200Hz→20Hz)
│   │   └── GUI_Task周期放宽 (1ms→5ms)
│   └── 否 ↓
├── 检查I2C通信
│   ├── 软件I2C时序?
│   └── 中断是否打断I2C?
├── 检查触摸芯片
│   ├── RST/INT引脚时序
│   └── GT9147配置正确?
└── 检查LVGL轮询周期
    └── lv_task_handler 5ms
```

## 继电器问题

```
继电器不动作?
├── 检查GPIO输出
│   ├── 万用表测PB15/PC6
│   ├── 无输出 → 检查代码逻辑
│   └── 有输出 ↓
├── 检查继电器驱动
│   ├── 三极管/MOS管
│   └── 续流二极管
└── 检查PWM
    ├── TIM4 CH2/CH3输出?
    └── 频率/占空比正确?

刷卡后停止键失灵?
├── 电阻屏? → 电磁干扰
│   ├── 加帧校验
│   ├── 加命令重发
│   └── 刷卡后延迟100ms
└── 电容屏? → 检查USART帧完整性
```

## 倒计时问题

```
倒计时结束红灯不亮?
├── 追踪LED_Flag
│   ├── 是否=2?
│   │   └── 否 → 检查状态机逻辑
│   └── 是 ↓
├── 检查osDelay阻塞
│   ├── 阻塞期间计数器是否归零?
│   │   └── 是 → 状态变量移到阻塞前
│   └── 否 ↓
├── 检查all_off指令
│   ├── 是否锁死后续写入?
│   │   └── 是 → 去掉all_off, 只发red_on+buzzer_on
│   └── 否 ↓
└── 检查competition()调用
    └── 是否被正确调用?
```

## 编译问题

```
编译报错?
├── 头文件找不到 → 检查Include路径
├── 符号未定义 → 检查源文件是否添加
├── scatter文件找不到 → 检查.sct路径
└── 语法错误 → 检查代码

Flash下载失败?
├── No ST-LINK → 检查连接
├── No Algorithm → 添加Flash算法
├── Target DLL cancelled → 重新连接
└── 检查BOOT0引脚 (应为0)
```

## 复位问题

```
不定期复位?
├── 读RCC_CSR
│   ├── IWDGRSTF → 代码死等/喂狗不足
│   ├── BORRSTF → 欠压/电源纹波
│   ├── PINRSTF → 外部复位/NRST电路
│   └── SFTRSTF → 软件复位/NVIC_SystemReset
├── 检查电源纹波
│   └── 加电容/放电电阻
└── 检查堆栈溢出
    └── 增大任务栈/检查递归
```
