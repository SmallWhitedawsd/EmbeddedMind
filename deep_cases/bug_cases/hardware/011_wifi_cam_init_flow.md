# 011: WiFi摄像头libCamera.so初始化流程分析

## 项目
WIFI_CAM (Android/libCamera.so逆向分析)

## 环境
Android, libCamera.so, 摄像头: WIFL_8K

## 现象
需要理解摄像头初始化流程以定位问题

## 影响范围
摄像头功能开发

## 排查过程

### 假设1: 视频流初始化代码
- 验证方法：分析strings/BaseCmd.java
- 结果：找到视频流相关命令

### 假设2: init流程
- 验证方法：分析libCamera.so init flow
- 结果：找到初始化序列

## 根因
摄像头初始化需按特定顺序：上电→复位→加载固件→配置寄存器→启动视频流

## 修改方案
```java
// BaseCmd.java中的命令序列
// 1. 上电时序
// 2. 复位(RESET引脚)
// 3. 加载固件(通过SCCB/I2C)
// 4. 配置分辨率/帧率
// 5. 启动视频流
```

## 验证结果
理解初始化流程后可正确控制摄像头

## 预防措施
- 摄像头上电时序严格按手册
- 复位后需等待稳定
- 寄存器配置需逐位验证

## 经验规则
- 摄像头初始化失败→查时序
- 无视频流→查寄存器配置
- 花屏→查数据格式匹配
